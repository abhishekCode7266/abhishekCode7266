# Web Development Mini Projects 🎯

A collection of interactive web-based mini projects built with **HTML**, **CSS**, and **JavaScript**. Each project demonstrates fundamental web development concepts and interactive functionality.

---

## 📋 Projects Overview

### 1. **Tic Tac Toe** 🎮
A classic two-player Tic Tac Toe game with an interactive board.
- **Features:**
  - Two-player gameplay (Player X vs Player O)
  - Win detection algorithm
  - Reset/New Game functionality
  - Interactive UI with hover effects
- **File:** `Tic Tac Toe.html`

### 2. **Stopwatch** ⏱️
A fully functional stopwatch application with timer controls.
- **Features:**
  - Start/Stop/Reset controls
  - Millisecond precision
  - Lap recording capability
  - Real-time display
- **File:** `stopwatch/` folder

### 3. **Calculator** 🧮
A functional calculator for basic arithmetic operations.
- **Features:**
  - Addition, Subtraction, Multiplication, Division
  - Clear and Delete functionality
  - Decimal support
  - Responsive button layout
- **File:** `Calculator.html`

### 4. **QR Code Generator** 📲
Generate QR codes from text or URLs.
- **Features:**
  - Text to QR conversion
  - Real-time QR generation
  - Download QR code
  - Copy to clipboard
- **File:** `QR.html`

### 5. **Quiz App** 📚
An interactive multiple-choice quiz application.
- **Features:**
  - Question bank with multiple choices
  - Score tracking
  - Answer validation
  - Results display
- **File:** `Quiz App.html`

### 6. **To-Do List** ✅
A task management application.
- **Features:**
  - Add new tasks
  - Mark tasks as complete
  - Delete tasks
  - Local storage persistence
  - Task counter
- **File:** `To-do List.html`

### 7. **Clock** 🕐
A digital/analog clock displaying real-time.
- **Features:**
  - Real-time clock display
  - 12/24-hour format toggle
  - Analog clock visualization
  - Digital time display
- **File:** `clock.html`

### 8. **Notes App** 📝
A simple note-taking application.
- **Features:**
  - Create and edit notes
  - Local storage for persistence
  - Delete notes
  - Search functionality
  - Color-coded notes
- **File:** `notes.html`

### 9. **Password Generator** 🔐
Generate secure random passwords.
- **Features:**
  - Customizable password length
  - Character type selection (uppercase, lowercase, numbers, symbols)
  - Copy to clipboard
  - Password strength indicator
  - Regenerate option
- **File:** `password Generator.html`

## 🚀 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abhishekCode7266/abhishekCode7266.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd "web development_mini project"
   ```

3. **Open any project in your browser:**
   - Simply double-click the `.html` file, or
   - Right-click and select "Open with" your preferred browser, or
   - Use a local server (recommended):
     ```bash
     python -m http.server 8000
     # or for Python 2
     python -m SimpleHTTPServer 8000
     ```
