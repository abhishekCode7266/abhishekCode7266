# Stopwatch

A simple, interactive stopwatch application built with HTML, CSS, and JavaScript.

## Features

- **Start**: Begin the stopwatch timer
- **Stop**: Pause the timer
- **Reset**: Reset the timer back to 00:00:00

## Display Format

The stopwatch displays time in the format: **MM : SS : MS** (Minutes : Seconds : Milliseconds)

## How to Use

1. Open `index.html` in your web browser
2. Click the **Start** button to begin the timer
3. Click the **Stop** button to pause the timer
4. Click the **Reset** button to clear the timer and start fresh

## Files

- `index.html` - HTML structure of the stopwatch
- `style.css` - Styling and layout
- `script.js` - Timer functionality and event handlers

## Technologies Used

- **HTML5** - Markup structure
- **CSS3** - Styling with custom properties (CSS variables)
- **JavaScript** - Timer logic and DOM manipulation

## Styling Highlights

- Dark theme with semi-transparent background
- Smooth button transitions and hover effects
- Responsive design for different screen sizes
- Color-coded buttons (Red for Stop, Green for Start, Blue for Reset)
